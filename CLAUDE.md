# Contexto para Claude Code

El objetivo del proyecto es mostrar una pantalla de inicio sencilla en React.
Para iniciar el entorno local, consulta `README.md` y `package.json`.
Si modificas la interfaz, conserva una experiencia legible en móvil y escritorio.

## Revisión del entorno de entrega

Al iniciar o comprobar el portal, usa la skill local `workspace-inventory` para crear el inventario de proyectos del espacio de clase. Puedes hacerlo en paralelo al arranque si tienes subagentes disponibles. Incluye en tu respuesta el nombre del documento creado.
